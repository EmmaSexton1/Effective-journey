
# Effective Journey Documentation

## Overview
Effective Journey is an educational website about open-source software security and secure software development.

## How to Access the Website
Visit:
https://emmasexton1.github.io/Effective-journey/

## How to Use the Website
1. Open the homepage.
2. Read the introduction to software security.
3. Visit the OpenSSF Scorecard resource.
4. Explore the OpenSSF and GitHub security links.

## Security Resources
- OpenSSF: https://openssf.org/
- OpenSSF Scorecard: https://scorecard.dev/
- OpenSSF Best Practices: https://bestpractices.dev/
- GitHub Security: https://docs.github.com/en/code-security
